# Project agent memory

- POM plugin `comfyui` (`pom-plugin-comfyui`), created from the POM `creating-pom-plugins` skill. The contract lives in the POM repository: `docs/subsystems/plugins-ui.md` and `docs/subsystems/enterprise-licensing.md`.
- `src/abi.rs` is the C ABI v1 boundary (entry `pom_comfyui_plugin_v1` in `src/lib.rs`); keep domain code out of it. `src/lib.rs` dispatches `host.*`, `ui.*`, `rpc.*` and `peer.*` operations; `src/context.rs` reads `host.configure`.
- `query` must answer at once: the node waits 3 s and one slow call blocks every other. Slow work (downloads, child processes, indexing) runs on a thread the plugin owns.
- The plugin host speaks IPC over its own stdin/stdout: any child process gets `Stdio::null()` for stdin and a log file for its output, never the inherited streams.
- Secrets (`gateway.api_key`, `host_api.token`, upstream tokens) never appear in `rpc.*` replies, `host.services`, logs or screens.
- `ui/manifest.json` is the `pom-plugin-ui/v1` screen contract; `release/manifest.json` is the release contract (ABI, feature set, preferences). `ui/src/host/runtime.ts` and `ui/src/host/ready.ts` are the only files that read `__POM_HOST__`. CSS classes use the `pb-` prefix, which `ui/build.mjs` renames to the plugin code.
- `scripts/build-ui.sh` generates the ignored `ui/dist/`; `scripts/package.sh` builds an installable artifact and the per-platform GitHub manifest. The POM local rebuild runs `development.rebuild` with the source read-only (`scripts/dev-ui.sh` writes to `POM_PLUGIN_OUT_DIR`).
- ComfyUI integration (mirrors `pom-plugin-hermes`): `lifecycle: on_demand`, full-bleed iframe of `/api/ui/plugins/comfyui/proxy/`. `src/installer.rs` pins the ComfyUI release tarball (`VERSION`/`SOURCE_URL`/`SOURCE_SHA`) and `uv` 0.13.5, creates `<plugin dir>/venv` with a managed Python 3.12 and installs `torch torchvision torchaudio -r requirements.txt` in ONE `uv pip install --torch-backend <cu130|cu128|rocm6.4|cpu|auto>` (`cu130` from NVIDIA driver 580: ComfyUI's comfy-kitchen CUDA kernels for int8/fp8 weights need it) so PyPI never swaps the GPU build. `.installed` holds `<sha> <backend>`; another backend (GPU change, `cpu_only`) reinstalls packages. Install steps run in their own process group (killed on stop); logs `install.log`, `bridge.log`, `comfyui.log` in the plugin dir.
- `runtime/bridge.py` (run by the venv Python with `-I`) starts ComfyUI with `--listen 127.0.0.1 --port <random> --base-directory <workspace>/.comfyui` plus `POM_COMFYUI_ARGS` (newline-separated, from preferences), in its own session; it checks `x-pom-plugin-token`, rewrites `Host` and `Origin` to the loopback server (ComfyUI's origin middleware 403s a mismatch), sends `Upgrade` once for `/ws`, strips `x-frame-options`/`set-cookie`, and on stdin EOF kills the process group. It exits when ComfyUI dies so the supervisor reports `error`.
- `runtime/pom_nodes.py` and `runtime/web/pom.js` are rewritten into `<home>/custom_nodes/pom_nodes/` on every start. In a browser ComfyUI's missing-model "Download" saves to the viewer's computer; `pom.js` sets `window.__comfyDesktop2.downloadModel` (the frontend's host hook) so it POSTs `/pom/models/download`, which fetches Hugging Face/Civitai files into the first POM model folder (`POM_MODEL_DIRS`) with room, as `<org>/<repo>/<file>` (`relative_destination`, which refuses a URL without both parts or with `.`/`..` segments, plus a realpath check that the target stays inside the folder; `choose_root`), then POSTs `host_api` `/catalog/refresh`; without model folders it falls back to ComfyUI's `models/<folder>`. `sync_links` reads `host_api` `GET /catalog/images` and keeps `models/<folder>/pom/<name>` symbolic links to POM's image files (`CATEGORY_FOLDERS`, `plan_links`, `sync_links_to`: only symlinks under `pom/` are created or removed, never a regular file; where a symlink cannot be made, as on Windows without the privilege, the file's own folder is registered with `folder_paths.add_model_folder_path`); it runs at import on a background thread, after each download and on `POST /pom/models/sync`, which `pom.js` calls when the page opens. `tests/test_pom_nodes.py` (stdlib `unittest`, ComfyUI modules stubbed) covers downloads and links. The node's gateway URL and key, its model folders (`host.configure.model_dirs`) and its `host_api` reach it only as `POM_OPENAI_BASE_URL`/`POM_API_KEY`, `POM_MODEL_DIRS` (newline-separated) and `POM_HOST_API_URL`/`POM_HOST_API_TOKEN` in ComfyUI's environment (`supervisor::bridge_env`; `bridge.py` passes its environment on). A change of any of them or of a preference (`Context::launch_identity`) restarts ComfyUI.
- Verify with `scripts/build-ui.sh && POM_UI_REQUIRE_DIST=1 cargo test --locked && cargo fmt --check && cargo clippy --locked --all-targets -- -D warnings && tests/test_ci_plan.sh && python3 -m unittest discover -s tests -p 'test_*.py'`.
